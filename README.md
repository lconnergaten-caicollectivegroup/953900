# Fun Maps Sales Pilot

Authenticated, ADHD-supportive 30-day sales workspace for the San Diego Fun Maps team.

## Features
- Supabase email/password authentication
- Lead and pipeline tracking
- Weekly targets and conversion indicators
- Accountability checklist and Momentum Coach
- San Diego opportunity hotspot view
- Owner-scoped row-level security

## Lovable launch
1. Rename this repository to `fun-maps-sales-pilot`.
2. Import it into Lovable.
3. Connect a dedicated Supabase project.
4. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
5. Apply `supabase/migrations/001_fun_maps.sql`.
6. Run the Lovable Security scan and resolve every error-level finding.
7. Publish and have a genuine user register, confirm email, sign in, and add a lead.

Never place a service-role key in frontend variables.
