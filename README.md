# Fun Maps Regional Revenue Command Center

Phase 1 is a 30-day regional sales validation pilot. Fun Maps is the project and client brand; Charley is the first pilot sales rep, not the product name.

## Pilot scope

- One regional sales rep across San Diego, Palm Springs, Laguna Beach, and Los Angeles
- Two qualified closing conversations per day
- Week 1 target of 2–3 sales and Week 2 target of 4–6 sales
- Weekly actual-versus-target and required-versus-achieved conversion tracking
- Annual advertising inventory and pricing guidance
- Priority closing conversations, account-level revenue signals, activity logging, and follow-up
- San Diego as the first market-intelligence proof view
- Day 30 retainer, revenue-share, or close-the-pilot decision

Targets are Fun Maps operating goals for validation and are not CAI performance guarantees.

## Roles

- Charley — regional sales rep and Phase 1 pilot user
- LaShea — platform administrator and revenue advisor
- Alan — executive read-only viewer

## Local development

```bash
npm install
npm run dev
```

Supabase email/password authentication remains optional. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to enable it. The command-center data in this pilot build is demonstrative and does not represent a live CRM integration.
